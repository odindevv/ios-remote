# iOS Remote

## Requirements

- Windows PC
- Python 3.10+ (tick **Add to PATH** when installing)
- iTunes or **Apple Devices** (Microsoft Store)
- Sideloadly

## Setup (once per PC)

1. Double-click `SETUP.bat`.
2. Double-click `TEST.bat`. It must end with **ALL GOOD**.

## Setup (once per iPhone)

1. Plug the iPhone in, unlock it and tap **Trust**.
2. In Sideloadly, install `wda/WDA-oficial-16.14.0.ipa` on the iPhone.
3. On the iPhone: Settings → General → VPN & Device Management → trust the profile.
4. On the iPhone: Settings → Privacy & Security → **Developer Mode** → On. Restart and confirm.

## Daily use

1. Plug in the iPhone and unlock it.
2. Double-click `START.bat`.
3. On the **Phones** page, press **▶ Start** on the phone and wait until it says **ready**.
4. Click the phone to control it.
5. To finish, press **Stop** or close the black window.

## Every 7 days (free Apple ID)

Reinstall `wda/WDA-oficial-16.14.0.ipa` with Sideloadly.
